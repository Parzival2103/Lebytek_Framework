## Not enabled by default

- Vertical `invoicing` remains **OFF**. Do **not** set `FACTURAPI_ENABLED` / enable vertical in production until consumer webhook secret, RBAC roles, and ops runbook are ready.

## Consumer migration

1. PHP **≥8.2**.
2. Backup `composer.lock`; `composer update lebytek/framework --with-dependencies`.
3. If upgrading from &lt;1.2.8: audit CRUD `uploads.enabled=true` for mandatory `allowed_extensions` (C6).
4. Run migrate/install wrapper; smoke `/admin/sistema/estado` → `v1.2.9`.
5. Rollback: restore prior lock + previous tag.
