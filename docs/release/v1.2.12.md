# Release v1.2.12 — Optional checkout idempotency key

## Included (installable via `composer require lebytek/framework:1.2.12`)

| Area | Notes |
|------|-------|
| Payments CheckoutRequest | Nuevo param opcional `?string $idempotencyKey = null` + getter `idempotencyKey()` |
| StripeGateway::createCheckout | Usa `idempotencyKey` si no vacía; si no, `externalRef()` (comportamiento previo) |
| Metadata | `order_public_id` sigue siendo `externalRef()` — sin cambio de webhook lookup |

## Consumer migration

1. PHP **≥8.2**.
2. Backup `composer.lock`; `composer update lebytek/framework --with-dependencies`.
3. Callers existentes que no pasan `idempotencyKey` no cambian de comportamiento.
4. Portal cobros admin: pasar `idempotencyKey: "{public_id}-a{n}"` al reabrir Checkout.
5. Rollback: restore prior lock + tag `v1.2.11`.

## Not in this release

- Stripe Payment Links API
- Rename of metadata key `order_public_id`
- Subscription checkout idempotency override (sigue usando `external_ref` / uniqid)
