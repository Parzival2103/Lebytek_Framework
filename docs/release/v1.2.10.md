# Release v1.2.10 — Platform (M4 `/api/health` + M3 CRUD RBAC router)

## Included (installable via `composer require lebytek/framework:1.2.10`)

| Area | Notes |
|------|-------|
| M4 public liveness | `GET /api/health` → `200 {"status":"ok"}` **before** `AuthMiddleware` group (harness + skeleton); `HealthController::health()`; `/api/ping` unchanged (session) |
| M3 CRUD/calendario RBAC | `CrudRoutePermissionResolver` + `CrudRbacMiddleware` on `/admin/crud/*` and `/admin/calendario/*`; early 403 with slug (HTML/JSON); service-layer checks kept |
| Docs | Monitoreo § in `despliegue-y-versionado.md`; auth RBAC §5.1; `config/rbac_route_permissions.php` `crud_router` |

## Consumer migration

1. PHP **≥8.2**.
2. Backup `composer.lock`; `composer update lebytek/framework --with-dependencies`.
3. Point LB/cron at `/api/health` (not `/api/ping`).
4. Expect earlier 403s on CRUD/calendario when the user lacks `{permission_prefix}.*` — same slugs as before, now at router.
5. Smoke `/admin/sistema/estado` → `v1.2.10`; `curl -sf https://<host>/api/health`.
6. Rollback: restore prior lock + previous tag.
