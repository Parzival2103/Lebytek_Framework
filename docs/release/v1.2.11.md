# Release v1.2.11 — Platform (CRUD p04 CAS / bulk equality)

## Included (installable via `composer require lebytek/framework:1.2.11`)

| Area | Notes |
|------|-------|
| CRUD CAS transitions (C4) | `CrudTransitionService` persiste con `WHERE pk AND deleted = 0 AND {column} = :from`; reintento ×1; conflicto accionable |
| CRUD update / soft-delete (G13) | Mutaciones condicionadas a `deleted = 0`; mismo reintento ×1 y mensaje de conflicto |
| CRUD bulk parity (G1) | `runBulk` revalida `isVisibleFor` / `isEnabledFor` con el mismo mensaje que `run` (best-effort) |
| CRUD equality fail-closed (G14) | `equalityMatches` sin coerción `(string)null → ''`; list SELECT incluye columnas de condiciones |
| Docs | `modulo-crud-engine.md` § Fase 1 actions + § states/transitions |

## Consumer migration

1. PHP **≥8.2**.
2. Backup `composer.lock`; `composer update lebytek/framework --with-dependencies`.
3. Smoke `/admin/sistema/estado` → `v1.2.11`; ejecutar acciones CRUD de transición y bulk en staging.
4. Si condiciones `visible_when` / `enabled_when` referencian columnas no listadas, el motor ya las incluye en el SELECT — no requiere cambio JSON salvo demos con columnas inexistentes.
5. Rollback: restore prior lock + tag `v1.2.10`.

## Not in this release

- Invoicing vertical remains **OFF** (use `v1.2.9` surface; do not enable Facturapi in prod from this bump alone).
- M3 CRUD router RBAC and M4 `/api/health` shipped in **v1.2.10** — unchanged here.
